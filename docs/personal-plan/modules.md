# Modules

Use one seeded fictional wholesale distributor from end to end and a second fictional workspace for permission tests. The MVP column defines the working personal version after deepening the first thin slice. Stretch work extends the same contracts.

| Module | Personal MVP | Stretch | Demo or training data |
| --- | --- | --- | --- |
| Governance core | Workspace and record permissions, scoped bot identities, policy settings, approval inbox, pause control and append-only audit export. | More granular delegation, bulk policy simulation and richer audit search. | Fictional actors, role grants, policies, consent flags, action intents and outcomes. |
| Native REST and MCP | One typed tool catalog through scoped REST and Streamable HTTP MCP. Call native records and one read-only external adapter, with freshness and sync status. | Odoo Community and ERPNext adapters, more accounting and CRM connectors, signed webhooks, reconciled writes and scoped upstream MCP tools. | Stable fake IDs, sandbox records, source versions, cursors and change events. |
| Native ERP | Small custom operational core for items, orders, suppliers, stock movements, requisitions, POs and receipts. Seed balances or read them from an accounting sandbox. Export CSV for handoff. | Multiple stock locations, partial shipments, returns, three-way matching and richer accounting-system handoff. | Synthetic SKUs, orders, movements, vendor terms, invoices, credits and payment events. |
| Native CRM | Companies, contacts, owners, deal stages, activities and consent and suppression history, linked to ERP accounts. | Duplicate resolution, configurable pipelines, more import mappings and deletion tools. | Fictional accounts, contacts, deals, activity events and channel permissions. |
| Inbound chat | LangGraph web chat with approved help content, verified test-session order lookup and human handoff to a demo inbox. | Draft quote intake, knowledge search and multilingual tests. | Fictional FAQs, orders, identity challenges and handoff transcripts. |
| Inbound voice | Browser voice with speech input and playback, interruption, the same LangGraph tools as chat and a handoff path. | Local SIP/Asterisk test line and queue, RingCX routing, French and noisy-audio tests. | Owner-recorded or generated test utterances, fictional order references and audio timing events. |
| PR-to-PO bot | Turn a purchase requisition into a draft PO, check vendor, lines, cost centre and budget, and create the native PO once after approval. | Request for quote, bid comparison, approval chains and receipt matching. | Fictional PRs, suppliers, SKUs, budgets, quantities, prices and terms. |
| Collections email | Draft an invoice reminder against the authoritative test balance, approve it and deliver to Mailpit. Recheck balance and suppression at send time. Hold disputes for a person. | Promise and payment reconciliation, reply triage and provider sandbox adapters. | Synthetic aging, invoices, payments, balances, recipient permissions, cadence and replies. |
| Collections outbound voice and SMS | Run bounded reminder scripts and templates through simulated dispatch, with recipient verification, opt-out, shared cadence, approval and a stop switch. | Carrier sandbox delivery, voice transfer and improved delivery and suppression reconciliation. | Fictional opt-ins, contact windows, identity challenges, disputes and provider receipts. |
| Customer workflow builder | Visual graph with event or schedule trigger, condition, delay, approval and typed action. Build a win-back email, preview it without side effects, publish a version and inspect its run in Mailpit. | Reusable templates, mapping nodes, visual run debugging and controlled replay. | Fictional purchase recency, account segments, consent, rules, schedules and synthetic events. |
| Fraud review | Queue orders using explainable rules and a trained scikit-learn classifier. Compare both at fixed review capacity on held-out data. The reviewer decides disposition. | Boosted trees, calibration, drift checks and shadow scoring. | Generated orders and mature outcome labels. Use licence-reviewed PaySim as an optional public pipeline benchmark. Split by time and avoid leaking related accounts or future chargebacks. |
| Sales and demand prediction | Weekly sales and SKU/location demand forecasts, baseline and trained candidate, uncertainty ranges and rolling backtests at replenishment lead time. Abstain for sparse history. | Hierarchical forecasts, promotion scenarios and stock-out-aware estimation. | Synthetic sales, returns, stock-outs, promo calendars and lead times. Use licence-reviewed public M5 series for comparison. |
| Fine-tuned customer profiling | Define a small business taxonomy, compare grounded prompting with a small LoRA adapter trained on fictional data, and route cited suggestions to review. Fetch current facts from CRM at inference time. | More domain taxonomies, per-workspace adapters and multilingual evaluation. | Fictional purchase histories and human-reviewed labels. Hold out newer, disjoint accounts and measure segment quality, citation accuracy, abstention and leakage. |
| Native LLM API and BYO | Own a streaming API with structured responses and route selection. Serve a local model, support an OpenAI or Anthropic test route where available, and exercise adapter contracts for ElevenLabs speech and RingCX contact centre independently. | Implement the remaining adapters, optional Canadian hosted inference and explicit inference-only fallback. | Synthetic prompts, approved fixture knowledge, schemas, route capabilities and redacted token/audio metrics. |
| Modular subscriptions | Store a demo subscription with module grants and allowances. Enforce grants and caps at execution and show deduplicated usage by unit. | Scheduled grant changes, allowance resets and manual adjustments. | Fictional subscriptions, module switches, allowance windows and provider or action usage events. |

Record dataset rights, provenance, split rules and artifact versions. Keep the fraud rules, forecast baselines and grounded profiler available for comparison and rollback. Evaluate on synthetic and licence-reviewed public data. These experiments measure behavior on the demo cases and benchmarks.
