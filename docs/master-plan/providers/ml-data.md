# ML and data providers for SMBs

**Checked 2026-11-24 (Toronto) using live public documentation.** Prices are displayed in the vendor's currency (US$ below for US-listed schedules, CA$ where stated), before tax, overage and negotiated charges. **Quote** means a public rate for the relevant product was unavailable. **Unconfirmed** means no Canadian deployment for that product was verified in public documentation. A regional data plane alone does not establish where support, logs, backups, subprocessors, disaster recovery, or optional AI features operate. **MCP unverified** means no first-party server for the relevant workflow was confirmed. SDKs, REST APIs and documentation feeds are listed separately from MCP.

**Decision.** Launch with first-party order rules and a reviewer queue, batch demand forecasts, and tenant-local customer segments. Run the native stack in one Canadian cloud region. Offer Stripe Radar or Wyllo for payment fraud, Trulioo for identity/KYB, and Hightouch for customers with a warehouse. Add TimeGPT as a benchmark-gated forecasting upgrade and Signifyd for merchants that can make use of a chargeback guarantee.

Implementation and release gates live in the [data and ML plan](../04-data-ml-plan.md) and [governance plan](../05-governance-security-compliance.md).

Federated training keeps raw records with each participant. Use authenticated clients, secure aggregation and a minimum round cohort if piloted. Updates and final models can still leak information.
